# Learn Albanian with Debora — logo files

The logo is the wordmark "LEARN Albanian with Debora": a plis (the traditional white felt cap) sits on the
capital A, with a band of qilim diamonds above the handwritten "with Debora". All text is converted to
outlines, so the files need no fonts installed.

| File | Use |
|---|---|
| `logo.svg` | Main logo, transparent background. Use on light backgrounds. Scales to any size. |
| `logo-light.svg` | Ivory version for black backgrounds (the website footer). |
| `logo-compact.svg` | Small lockup without the qilim band, for tight spaces (the website header). |
| `logo-on-sand.png` | Main logo on the sand (#F3EFE6) square, 1200 px. Social posts, profile headers. |
| `logo-light-on-black.png` | Ivory logo on a black square, 1200 px. |
| `logo-transparent.png` | Main logo, transparent background, 1540 px wide. |
| `app-icon.png` | The A with its plis on red, rounded, 1024 px. Profile pictures, WhatsApp Business, etc. |
| `app-icon.svg` | Vector version of the app icon. |

Colours: red #E41E20 · ink #1F1F1F · ivory #FFFDF7 · sand #F3EFE6.
Typefaces in the logo: Nunito Sans Light (LEARN), Fraunces ExtraBold (Albanian), Caveat SemiBold (with Debora).
Fonts on the website: Fraunces (headings) and Nunito Sans (body).
