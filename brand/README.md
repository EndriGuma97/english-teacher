# Learn Albanian with Debora — logo files

The brand mark is a stylised, geometric double-headed eagle in Albanian red (#E41E20).
It is an original drawing, not the official coat of arms.

| File | Use |
|---|---|
| `logo-eagle-red.png` | Main mark, red on transparent, 1024 px. Use on light backgrounds. |
| `logo-eagle-black.png` | Black on transparent, 1024 px. For single-colour print. |
| `logo-eagle-white.png` | White on transparent, 1024 px. For dark or red backgrounds. |
| `logo-eagle-on-ivory.png` | Red mark on the site's ivory (#FFFDF7) square, 1024 px. |
| `logo-eagle-app-icon.png` | Rounded app-icon style, 1024 px. Social profile pictures, WhatsApp Business, etc. |
| `logo-eagle-app-icon.svg` | Vector version of the app icon. Scales to any size. |

Colours: red #E41E20 · black #000000 · ivory #FFFDF7 · sea blue #1B4F8A.
Fonts on the website: Fraunces (headings) and Nunito Sans (body).
